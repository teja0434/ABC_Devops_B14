The standard and most universal way to remove a user from a secondary (supplementary) group in Linux is by using the gpasswd command.
Method 1: Using gpasswd (Recommended)
This command works reliably across virtually all Linux distributions (Ubuntu, Debian, CentOS, RHEL, Fedora).
bash
sudo gpasswd -d username groupname
Use code with caution.
Replace username with the user's name and groupname with the target group.
Method 2: Using deluser (Ubuntu / Debian Only)
If you are running Ubuntu, Debian, or their derivatives, you can use the more intuitive deluser utility.
bash
sudo deluser username groupname
Use code with caution.
(Note: This will not work on RHEL, CentOS, or Fedora).
Step 3: Verify the Changes
After running either command, you should verify that the user was successfully removed using the groups or id command:
bash
groups username
# OR
id username
Use code with caution.
Important: Primary vs. Secondary Groups
The methods above apply to secondary groups (also known as supplementary groups).
If the group you are trying to remove is the user's primary group (the default group assigned when the user was created), the system will prevent you from removing it directly. To handle this:
1. First, assign the user a new primary group using usermod:bash
sudo usermod -g new_primary_group username
Use code with caution.
2. Then, you will be able to delete the old group or remove the user from it safely.
